# 桃園市立楊梅高級中學 語音電話分機互動資訊網

本系統為 **桃園市立楊梅高級中學** 專屬的現代化全響應式（RWD）語音電話分機互動查詢系統。支援手機、平板與電腦無縫操作，並提供「處室組織」與「校園建築空間導覽」雙維度視覺化互動查詢。

---

## 🌟 核心特色與功能

1. **跨裝置極致體驗（Mobile / Tablet / Desktop）**：
   - 📱 **手機端**：單手操作友善、置頂搜尋列、大按鈕一鍵撥號（代入總機與逗號延遲自動轉分機 `tel:034789618,分機`）。
   - 📱 **平板端**：自適應雙欄佈局，分類標籤與卡片並陳。
   - 💻 **電腦端**：多欄響應式網格、鍵盤快捷鍵（按 `/` 立即聚焦搜尋、`Esc` 清除）、一鍵切換「卡片網格」與「緊湊表格清單」、一鍵複製分機與 Toast 提示。
2. **雙維度視覺化導覽**：
   - **處室組織模式**：依校長室、教務處、學務處、總務處、輔導室、圖書館、實習處、人事會計、導師室、專任辦公室、專科實驗室分類，並附有專屬色條與計數。
   - **校園建築空間導覽**：可點選 **悅知樓**、**日新樓**、**蘊慧樓**、**御風樓**、**生科大樓**、**行政大樓**、**啟明樓**，即時檢視各棟大樓所屬分機與樓層。
3. **即時智慧模糊搜尋與關鍵字高亮**：
   - 不僅支援分機號碼、職稱、姓名搜尋，還內建校園業務關鍵字（如：`成績單`、`在學證明`、`請假`、`午餐`、`修繕`、`借球`、`保健室` 等常用業務）。
4. **⭐ 我的常用分機（我的最愛）**：
   - 點擊卡片右上角星號即可將高頻聯繫的分機釘選在最上方。
   - 資料自動保存在使用者的瀏覽器（LocalStorage），不需登入也不會遺失。
5. **外線專線與傳真醒目標籤**：
   - 人事室、會計室、教務處、學務處、校安中心、總務處、輔導室、圖書館、員生社之外線電話與傳真均有獨立徽章。
6. **支援一鍵列印**：
   - 內建 `@media print` 專用排版，點擊「列印」即可自動隱藏導航列並產生乾淨整齊的紙本清單。

## 🚀 如何使用與部署

### 1. 本地直接使用
- 直接雙擊開啟 `index.html`，即可在任何現代瀏覽器（Chrome、Edge、Safari、Firefox）流暢運行。
- 支援完全離線使用（卡片圖示皆為內建向量 SVG，無破圖風險）。

### 2. 部署到學校網站或雲端
- **學校現有網頁伺服器**：將 `index.html` 與 `data.js` 上傳至學校 Web 空間任何目錄即可。
- **GitHub Pages / Vercel**：將本資料夾推送至 GitHub Repository，並開啟 GitHub Pages 即可擁有全域 HTTPS 網址。

### 3. 未來如何修改或新增分機？
- 打開 `data.js` 檔案，內部資料結構清晰直覺（包含 `deptName`、`title`、`name`、`ext`、`buildingName`、`floor` 等），直接以文字編輯器修改儲存即可，不需要重新編譯！
